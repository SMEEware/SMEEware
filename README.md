## `whoami`

I'm a software engineer in training focused on understanding computers beyond the abstraction layer: how software is built, how operating systems behave, how vulnerabilities emerge, and how defenders can detect and understand offensive techniques.

My learning path combines hands-on labs, reverse engineering, low-level development, and practical software projects. I prefer understanding the underlying mechanism over blindly running a tool.

> **Current direction:** Offensive Security / Red Teaming, Malware Development, Exploit Development, and Applied Cryptography.
